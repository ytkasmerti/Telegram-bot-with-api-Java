# Описание:
Telegram бот для получения информации о животных, породах кошек и собак. Отправляет данные и фотографии (только для пород) по запросу. Названия и породы необходимо вводить на английском языке.
# Как запустить:
## 1. Получите API ключ:
- Зарегистрируйтесь на сайте https://api-ninjas.com/
- Перейдите на страницу https://api-ninjas.com/profile
- Скопируйте ваш API ключ
## 2. Создайте своего бота (или используйте существующего):
- Напишите в Telegram @BotFather
- Создайте нового бота командой /newbot
- Получите токен бота
## 3. Создайте файл config.properties
В папке с файлом AnimalsInformer.jar создайте текстовый файл config.properties и добавьте в него следующий текст:
BOT_NAME=сюда_вставьте_любое_имя_бота
BOT_TOKEN=сюда_вставьте_токен_бота_от_BotFather
API_NINJAS_KEY=сюда_вставьте_ключ_с_api-ninjas.com
Важно: файл config.properties должен находиться в той же папке, что и AnimalsInformer.jar
## 4. Запустите jar-файл
Запустите файл AnimalsInformer.jar (out/artifacts/AnimalsInformer_jar/AnimalsInformer.jar) и используйте привязанного телеграмм-бота.
Также можно запустить с помощью консоли: "- java -jar [абсолютный путь к файлу AnimalsInformer.jar]". В этом случае в консоли будут отображаться сообщения от чатов с пользователями.
# Команды бота:
## Основные:
- start - начать работу с ботом
- help - показать список команд
## Выбор категории:
- кошка - поиск информации о породах кошек
- собака - поиск информации о породах собак
- животное - поиск информации о других животных
## Подсказки по полям:
- catinfo - перевод полей для кошек
- doginfo - перевод полей для собак
- animalinfo - перевод полей для других животных
