# НЕ ВЫКЛАДЫВАТЬ В ПУБЛИЧНЫЙ ДОСТУП!
## В репозитории лежит токен бота и API ключ с api-ninjas - их смогут украсть и использовать.

## Описание:
В классе main уже есть название бота, его токен и API-ключ c api-ninjas. При необходимости поменять либо реализовать чреез config.properties (как в публичном репозитории). 
apiKey здесь: https://api-ninjas.com/profil

Запустить файл AnimalsInformer.jar (out/artifacts/AnimalsInformer_jar/AnimalsInformer.jar) и использовать телеграмм-бота @Animals_Informer_Bot. 
Также можно запустить с помощью консоли: "- java -jar [абсолютный путь к файлу AnimalsInformer.jar]". В этом случае в консоли будут отображаться сообщения от чатов.

## Основные команды бота:
   - start - начать работу с ботом
   - help - показать список команд

   Выбор категории:
   - кошка - поиск информации о породах кошек
   - собака - поиск информации о породах собак
   - животное - поиск информации о других животных

   Подсказки по полям:
   - catinfo - перевод полей для кошек
   - doginfo - перевод полей для собак
   - animalinfo - перевод полей для других животных
